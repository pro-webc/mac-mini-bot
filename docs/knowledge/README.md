# `docs/knowledge/` — 運用ナレッジベース

実案件の実行から得られた **問題分析・原因特定・修正の効果測定** を蓄積する。
`docs/` 本体が「設計の正」を記述するのに対し、ここは「運用から学んだ事実」を記録する。

## 命名規則

```
YYYY-MM-DD_<短い識別名>.md
```

## 記録すべき内容

- **発生した問題**: 何が、どの案件・ステップで起きたか
- **根本原因**: ログ・トレースからの客観的な特定
- **実施した修正**: 変更したファイルと内容
- **効果の予測と評価**: 修正が問題を解消する確度と残存リスク
- **次のアクション**: 効果測定の方法、追加修正の候補
